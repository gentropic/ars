ars studio — help

Author content on a virtual reference mat; phones scan the printed mat and show the same scene anchored on the real table. The desk is the authority — what you see (and hide) here is what the phone shows.

quick start

  1. Print the mat — ars-mat-a4.pdf, page 2, printed at 100% scale (each black square must measure 80 mm; “fit to page” breaks the survey). Lay it flat, evenly lit.
  2. Add content — the add menu, or right-click the sheet to add at that spot. Drag to place (snaps to mm), arrows to nudge, inspector for exact numbers.
  3. Share — press share, scan the QR with the phone’s camera. Android Chrome offers start AR (world-anchored — scan once, walk around); everything else (iOS included) uses the magic-window (keep ≥2 markers in view).
  4. Save — file ▸ save project writes one .json carrying the whole scene, model files included.

data

Block models: CSV/TXT and Datamine .dm (sub-blocked included; no-grid models show as graded points) — pick the color column, ramp, and cutoff in the inspector. Point clouds: LAS. Meshes: STL (mm), PLY, GLB (m). One block/point model renders at a time. Eyes in the tree hide things on the phone too.
